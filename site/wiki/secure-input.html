貂毫在選單裡變灰、選不到

macOS 的防側錄模式（Secure Input）沒關的時候，系統會停用所有不是 Apple 的輸入法。怎麼認出來、怎麼解開。

是不是這個問題

三件事同時發生，幾乎就是它：

  • 輸入法選單裡的貂毫是灰的，點了沒反應。
  • 注音、ABC 這些 Apple 內建的輸入法照常能用。
  • 重新安裝、重新加入輸入法都沒用。

重裝沒用反而最像這個問題。Alfred、Raycast、TextExpander 這類要聽全部按鍵的工具同時失靈，就更確定了。

為什麼會這樣

點進密碼欄位時，程式會打開 macOS 的防側錄模式，鎖定畫面也會。開著的時候，系統停用所有第三方輸入法和聽按鍵的工具，你打的密碼不會被別的程式看到。

程式離開密碼欄位時應該把它關掉。有的程式忘了關，有的關到一半就結束，貂毫就一直是灰的。

貂毫解不開這個鎖：解得開的輸入法，就看得到你的密碼。這是 macOS 刻意的設計，每個第三方輸入法都一樣。貂毫能做的是告訴你系統記的是誰，照情況給解法（見下面的貂毫的提醒）。

依序試

1. 找在等你打密碼的視窗

最常見，也最容易漏看：瀏覽器停在登入頁的密碼欄位、系統在要鑰匙圈或 Apple 帳號的密碼、終端機的 sudo 在等密碼、密碼管理程式停在解鎖畫面。把密碼打完或關掉那個視窗就好。

2. 終端機的「安全鍵盤輸入」

終端機選單的「終端機 › 安全鍵盤輸入」，iTerm2 是「iTerm2 › Secure Keyboard Entry」。這是常駐的開關：勾了之後，只要終端機開著，防側錄模式就一直開著。有勾就取消。

3. 密碼管理程式：解鎖一次，或完全結束

1Password 的使用者論壇有不少人回報，1Password 開著時防側錄模式關不掉，而且系統常常記在登入視窗（loginwindow）或剛好在前面的程式頭上，照著名字去關別的程式當然沒用。

  1. 先打開 1Password 解鎖一次。
  2. 還是灰的，從選單列的 1Password 圖示選「結束 1Password」。只關視窗沒用，它還開在選單列。結束之後等幾秒，貂毫就選得到了。

要繼續用的話，更新到最新版。Bitwarden、LastPass 這類密碼管理程式也可能這樣，一樣先試這兩步。

4. 鎖定螢幕再解鎖

找不到是誰的時候，這招通常最快，也不用關掉任何程式：按 ⌃⌘Q 鎖定，等幾秒，再用密碼解鎖。不是每次都有用：程式一直抓著不放時，解鎖之後還是開著。

5. 登出再登入

一定有用，整個登入階段重來。要重新開機的話，把「重新登入時重新打開視窗」取消勾選，不然開著防側錄模式的程式會跟著回來，馬上又把它打開。

貂毫的提醒

防側錄模式開著超過一分鐘（螢幕鎖著的時候不算），貂毫會在螢幕右上角跳出小視窗，說系統記的是哪個程式、照情況該試什麼：

  • 系統記的程式還開著：先看它有沒有在等密碼，不然結束它。是終端機的話，多一步「安全鍵盤輸入」。名字有時候不對，結束了沒用就往下試。
  • 記在登入視窗（loginwindow）頭上：這個名字多半不對，先處理密碼管理程式。
  • 記的程式已經結束：結束別的程式都沒用，直接登出再登入。

有開著的密碼管理程式，提示會點名。防側錄模式一關，小視窗自己收掉；按「知道了」，這一次就不再跳。不要這個提醒的話，到蓬萊設定的「一般」頁關掉「防側錄模式卡住時提醒」。

每次跳出，貂毫在記錄檔資料夾（輸入法選單的「記錄檔…」）的 secure_input.log 記一行：時間、系統記的程式、開著的密碼管理程式。這個狀態登出就沒了，活動監視器也看不到，回報問題時請附上這個檔。

自己查是誰

打開終端機，貼上：

ioreg -l -d 1 -k IOConsoleUsers | tr ',' '\n' | grep SecureInputPID

沒有輸出，代表現在沒人開著，問題在別的地方。有輸出會像 "kCGSSessionSecureInputPID"=1234，數字是那個程式的編號，再用這行查名字（1234 換成查到的數字）：

ps -p 1234 -o comm=

這行印不出東西，代表程式已經結束、防側錄模式卻沒關，只能登出再登入。

查到的名字不一定是真正開著的程式。我們實測過：在終端機跑一支開防側錄模式的小程式，系統記成了當時在前面的瀏覽器；在另一台 Mac 記成了 Finder。查出 loginwindow、瀏覽器或 Finder 時，先回頭看密碼管理程式。
