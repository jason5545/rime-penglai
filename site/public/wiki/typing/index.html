打字、選字、送出

打注音時，注音先出現在游標處（組字區），旁邊的選字窗列出候選。選好之後按 Return 送出，字才真的進到文件裡。

組字區和候選

候選前面的數字對應 ⇧1～⇧9。每頁幾個候選可以在蓬萊設定的「選字窗」頁改（5～9 個）。

先按 ↓，再按數字

不想按 Shift 的話，先按一下 ↓，組字區後面出現〔選字：按數字〕，候選前面的 ⇧1… 換成 1…。這時直接按數字選字：

  • 選的候選只蓋住前面一段時，只選它，後面的留著，可以接著按數字選下一段。
  • 這時按 ↑ ↓ 照舊移反白；按其他鍵（Return、⌫、注音）就回到平常，那個鍵照原本處理。
  • 沒按 ↓ 的時候，數字鍵照舊是注音（1 是 ㄅ、3 是 ˇ）。

用 ⇧數字選字時，選完還要按 Return 才會送出。這樣一整句可以分好幾段慢慢選，全部選對再一次送出。

- 平常是 ㄦ，只有翻過頁之後才當「上一頁」。= 在選字窗開著時都是「下一頁」。

空白鍵：一聲、選字、補標點

空白鍵有三個用途，看打到哪裡：

  • 最後一個注音還能加聲調時，空白鍵是一聲。
  • 已經打了聲調，空白鍵是選字：選反白的那個候選，平常就是第一個。選完還沒送出。
  • 中文送出之後、組字區空著時，空白鍵是補標點：補上「，」，像問句時補「？」，見送出之後按空白補標點。

整句候選

一次打好幾個字時，選字窗最前面是整句的組合，蓬萊一次列出 5 種，後面才是比較短的詞：

這句是「今天天氣很好」，但還沒學過，第一個候選是「今天碳氫化合」。打過一次之後就會排第一，見只打第一個注音和打過的會記住。整句候選列幾種可以在蓬萊設定的「輸入」頁改（1、3、5）。

只選前面一段

整句不對，常常只是後半段錯。這時先選對前面那一段，後面的會留下來接著選：

  1. 按 ← 把游標往前移，選字窗只列游標前面那一段的候選。
  2. 選一個候選，前面那段就定下來了。
  3. 後面那段的候選接著出現，繼續選。

直接選一個比較短的候選（例如上面整句候選的第六個以後）也一樣：只蓋住前面一段，後面留著接著選。
