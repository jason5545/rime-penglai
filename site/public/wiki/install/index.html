安裝

貂毫還沒開放下載。

開放的時候，下載位置會寫在這一頁和首頁。在那之前，這份說明書可以先拿來了解蓬萊注音怎麼打。

先知道的事

  • 目前只有 macOS 版。
  • 貂毫跟官方的鼠鬚管用同一個使用者資料夾（~/Library/Rime）。兩個不要同時開著：同一份學習紀錄被兩邊開著時，後開的那個會學不到東西。
