安裝

到 GitHub 的最新版本下載 Sable-1.0.3.dmg，打開裡面的貂毫，按「安裝」。

先知道的事

  • 目前只有 macOS 版（Windows、Linux、Android 版待推出），要 Apple Silicon（M 系列晶片）的 Mac、macOS 13 以上。
  • App 用 Apple 的開發者憑證簽過、也送 Apple 公證過，第一次打開時 macOS 只會問一次「是從網路下載的，確定要打開嗎」。
  • 只裝給目前登入的使用者，不用管理員密碼。

安裝

  1. 下載 Sable-1.0.3.dmg，按兩下打開。
  2. 在打開的視窗裡按兩下「Sable」（貂毫），出現「安裝貂毫」時按「安裝」。
  3. 這台 Mac 第一次裝的話，macOS 會打開系統設定，問「要允許『貂毫』啟用『貂毫』嗎？」：按「允許」。這是 macOS 對每個第三方輸入法都會問的（輸入法看得到你打的字）。
  4. 它會把自己放進你的輸入法資料夾（~/Library/Input Methods），加進輸入法清單，再切換過去。看到「貂毫裝好了」就完成，DMG 可以退出、刪掉。
  5. 在任何能打字的地方開始打。第一次用要先準備詞典，等幾秒；接著會跳出一個小視窗，選好讀音就能打了（見第一次使用）。

裝好了，選單裡卻沒有貂毫

多半是系統設定問「要允許『貂毫』啟用『貂毫』嗎？」時沒有按到「允許」。1.0.0、1.0.1 會在這時跳出「沒有裝好」或「還差兩步」，剛好蓋住系統的詢問：先把那個視窗關掉，看系統設定裡有沒有這個詢問，有的話按「允許」就好，不用登出。

沒看到詢問，或已經按了「不允許」，就自己加入一次：打開「系統設定 › 鍵盤 › 輸入方式」，按「編輯⋯」再按左下角的「＋」，在「繁體中文」裡選「貂毫」加入。清單裡找不到的話，登出再登入一次再找。

更新

下載新版的 DMG，一樣打開裡面的貂毫，按「更新」。學習紀錄和設定在 ~/Library/Rime，不會動。每一版改了什麼見版本紀錄。

已經在用鼠鬚管

  • 貂毫跟鼠鬚管用同一個使用者資料夾（~/Library/Rime）。兩個不要同時開著：同一份學習紀錄被兩邊開著時，後開的那個會學不到東西。裝好貂毫之後，在輸入方式裡把鼠鬚管移除。
  • 你的 default.custom.yaml 如果自己寫了方案清單（schema_list），清單裡要加上 - schema: penglai_zhuyin，選單裡才會有蓬萊注音。

移除

  1. 先切換到別的輸入法，在「系統設定 › 鍵盤 › 輸入方式」選「貂毫」，按「－」。
  2. 在 Finder 按 ⌘⇧G，輸入 ~/Library/Input Methods，把 Sable.app 丟到垃圾桶。
  3. 學習紀錄和設定在 ~/Library/Rime，要一起清掉就把那個資料夾也刪掉。

原始碼

貂毫的原始碼、引擎的修改、詞典產生器和建置腳本都在 jason5545/rime-penglai，每一版的標籤（例如 v1.0.0）就是那個 DMG 建出來的原始碼。
